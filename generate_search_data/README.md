# Script for Generating the SynthNet Database
Combines meta data and LLM extracted PDF data and calculates embeddings for the synth-net app.

Run `generate_search_data.py` to create the following output files:
- `centroid_search_data.parquet`: Contains data on the aggregate level for item-based and scale-based centroids; data used in the SynthNet app.
- `item_search_data.parquet`: Contains data on the item level

Run `push_dataset_to_hf.py` to encrypt and push the generated dataset to Hugging Face. Requires an encryption key generated by `generate_key.py`. The Hugging Face dataset repository consitutes the central source of truth for the SynthNet app.

Run `read_search_dataset.py` to read and decrypt the dataset from Hugging Face for local testing.

NOTE: All operations assume that the raw data has already been generated by scipts in `document_extractor`.
